## Sound Generator + Kits v9.51 (in the patcher)

`1ef31cb7…7fca` (3,152,880 bytes), one guarded overlay generated by `synth/publish_v9_51.py`. It replaces

## Synthesized kits v9.46 (in the patcher)

The patcher has no build selector any more: it always builds Sound Generator +
Kits v9.46, which contains Sound Generator v9.9.3. The v9.9.3-only output and the
base build without synth additions are no longer offered, and the page no
longer loads `synth-data.js` or `waves-data.js` (both stay in the repository for
reproduction). `synth/test_browser.cjs` now checks the single build.
The page, the patcher panel and the done message say the build includes DOOM
OS 0.6.1 (build ED5E), with a DOOM OS card next to the Sound Generator and Kits
and a link to the DOOM OS quickstart.

Published as **Sound Generator + Kits v9.46**: build v9.46-test3 plus the
RESAMPLE start fix, APP1 SHA-256 `7b5fbcb4…684a` (3,094,624 bytes), one guarded
overlay generated by `synth/publish_kits.py`. It replaces v9.43 and the
experimental v9.44-test1 MIDI option, whose MIDI it includes; the patcher no
longer offers that test build (`kits-midi-data.js` removed). The page's drum kit
guide and MIDI guide now describe v9.46.

test3 adds the kits to the looper. With MARK Function set to Looper, the
LOOPER screen opened only the melodic Sound Generator (stock SHIFT + RECORD
SETTING). SHIFT + PATTERN EDIT there now opens the kits with the last kit, and
SHIFT + RECORD SETTING still opens melodic; both choose the machine at the press,
whatever the release order. REC on the Sound Generator screen records the loop
in kits mode as in melodic (stock behaviour, now checked in the emulator).

test2 answers the first hardware report on test1:

- Every recording loads. The SP's pad loader leaves a pad empty when its
  sample is shorter than 1,000 frames (21 ms), and REC gives no sign of it. In
  melodic mode a Pad Length of a few waveform cycles of a high enough note came
  under that (reported as "under 4 cycles doesn't record"). Such a recording
  now becomes the fewest whole cycles that reach 1,000 frames; Pad Lengths that
  already reach 1,000 frames and every time setting are unchanged. Drum REC and
  BOUNC never write under 1,000 frames either: a drum
  that rings out sooner runs on to it, and a silent capture writes 21 ms of
  silence.
- BOUNC into a bank that has samples asks once for the whole bank instead of
  once per used pad: FILL (the default) keeps the samples and fills the empty
  pads, OVER replaces them all. SURE? (NO by default) then confirms; NO writes
  nothing. An empty bank still fills at once.
- The emulator's storage model now refuses short samples as the SP does, so
  this can't slip through again. It reproduces the drum REC report on v9.44:
  that build's 462-frame drum recording at a Pad Length of −8 is refused.

test1 combines the open test branches into one build:

- v9.45-test1: BOUNC (the kit into a sample bank), drum REC at each drum's own
  length instead of the melodic Pad Length, and clean starts for the UDS, MP-7,
  TR-707 and TR-727 kits.
- v9.44-test1: external MIDI (M.CH, drum notes 36–51, CCs for every parameter).
- v9.43-test4: hot resample with the kits.
- RESAMPLE start fix: a resampled take's START lands on its first sound instead
  of keeping the effects chip's few milliseconds of round trip as silence. It
  applies when the first sound arrives within 50 ms; only START moves. Built as a
  stage after the kits (`synth/build_start_fix.py`), with
  `synth/test_start_fix.py`.

Emulator-checked only; hardware test pending. Try it in a scratch project.

## Synthesized kits v9.45 (test candidate, superseded by v9.46)

test1, built on v9.44-test1, so a kit dialled in on the synth can become a
normal sample kit:

- Drum REC fix: a drum recording now ends where the last of its drums has rung
  out (60 dB below its own peak, at most 10 s). It used to take the melodic Pad
  Length, which drum mode doesn't show; set to a waveform-cycle value, a drum
  REC saved only a few milliseconds. Melodic REC still uses Pad Length.
- Every hit of the UDS, MP-7, TR-707 and TR-727 kits starts its noise filters
  at rest, as the other kits do. A hit used to start with the filter memory of
  whatever its voice played last; right after a ringing open hat or cymbal that
  changed the first 0.5–2.5 ms of noisy hits such as the MP-7 quijada and snare
  or the TR-707 clap. The same pad now sounds the same every time.
- BOUNC, the last item of the drum VALUE menu: press VALUE, turn to a bank A–J,
  press VALUE. The kit's sixteen pads, each with its own Tune, Decay, Tone,
  Sweep, Noise, Attack and Level, are written into that bank's sixteen pads by
  the same code as a REC imprint. Empty pads are filled; for each pad that
  already holds a sample the item asks KEEP or OVER first (KEEP by default).
  The value counts the pads written. EXIT cancels; pads already written stay.
- Each sample is a first hit at velocity 127 and has the same length as a drum
  REC of it, with v9's 10 ms end fade. Pads with LEVEL 0 are left out. Files
  keep the stock imprint name SG.
- One new guarded jump in the stock exporter's length code (0x80132ac8) takes
  the drum length. Melodic REC writes the same files as in v9.44.
- New emulator tests: `synth/test_kit_bounce.py` runs drum REC (also with the
  two real REC presses) and every bounce through the real stock exporter with
  modelled storage; `synth/test_kit_restart.py` checks the clean starts. Hardware
  test pending: try it in a scratch project first.

## Synthesized kits v9.44 (test candidate, superseded by v9.46)

test1, for sequencing the Sound Generator from outside instead of resampling:

- M.CH, the last VALUE item in both modes (1–16, default 16), chooses the MIDI
  channel the Sound Generator plays while its page is open. 16 keeps the stock
  routing. With another channel, channel 16 stays the SP's control channel on
  every page. Changing M.CH stops held notes so none can hang.
- Drum mode: MIDI notes 36–51 play pads 1–16 as pad strikes (same sound, pad
  light, PAD, REC and arp behaviour). Other notes are ignored. They used to
  land on pads by note mod 16, from note 48.
- CCs on M.CH set every parameter, avoiding all CCs the SP already uses.
  Drums: Tune, Decay and Level for each pad (pads 1–4 CC 20–31, 5–12 CC 40–63,
  13–16 CC 102–113), plus Tone, Sweep, Noise and Attack (114–117) for the last
  pad heard; a drum CC selects its pad on screen. Melodic: TYPE 70, FREQ 71,
  LEVEL 72, DUTY 73, BALANCE 74, ENV 75, TUNE 76. Arp: 33–36. CC 123 and 120
  release MIDI notes and stop the arp; 120 also fades out every voice. RAM only.
- New emulator test `synth/test_kit_midi.py` drives the stock MIDI dispatcher on
  the built image. Hardware test pending.

## Synthesized kits v9.43-test4 (test candidate, superseded by v9.46)

Hot resample with the kits (stock: RESAMPLE, pick a pad, SHIFT + RECORD SETTING
opens the Sound Generator, and the first note starts the take):

- On the RESAMPLE screen with the take armed or running, SHIFT + PATTERN EDIT
  opens the Sound Generator in drum mode with the last kit. Before, it did
  nothing there.
- During a hot resample, SHIFT + PATTERN EDIT and SHIFT + RECORD SETTING on the
  Sound Generator page switch machines without starting or stopping the take.
  Before, their press started an armed take before any hit, or stopped a running
  one: the stock page starts and stops a resample on those keys without checking
  SHIFT. Unshifted presses still start and stop it.
- SHIFT + RECORD SETTING from the RESAMPLE screen opens the Sound Generator as

  booted image; with `--baseline` it reproduces the three faults on v9.43.
  Emulator-checked only.

## Synthesized kits v9.43 (2026-10-12)

test3, after the second hardware test:

- The drum VALUE menu no longer shows A.OCT, and drum arps ignore it, so an
  octave set in melodic mode cannot double drum hits.
- BPM is a readout: pressing VALUE on it no longer highlights it as if it could
  be edited (both modes).

test2, after the first hardware test:

- REC records drums struck together: the last struck pad plus up to three
  others struck within 100 ms before it, each at its own offset and velocity.
- The REC destination pad blinks again while it waits for the second REC press,
  in melodic and drum mode. The original polyphony patch had removed the stock
  pad redraw that ends every Sound Generator pad event; it is restored.
- The kit shortcuts do nothing while an imprint is armed (between the two REC
  presses), so they can no longer change state under a pending recording.
- FM kick no longer buzzes: its modulation index was 4–6 times too high. FM
  bells (pads 8 and 15) come down 4.4 dB to the kit's level.
- Kicks are louder: 2–7 dB, up to 3 dB above each kit's median loudness while
  keeping the attack clear of the limiter (808 +1.9 dB, DR-110 and KPR-77
  limited by their peaks).

test1:

- Thirteen kits: Lel' UDS (Soviet drum synthesizer) replaces Digi, Korg Mini
  Pops 7 replaces SY-1, and TR707 and TR727 are new. FM is rebuilt as eight
  DX-style voices with modulator feedback, including a log drum and cowbell.
- Every existing voice re-fitted to recordings, ACB captures and plug-in
  captures: pitch tracks, decays, envelopes and 1/3-octave balance.
- SWEEP 50 no longer adds a pitch blip; 50 is the authentic setting on every
  control. TONE drives the 808 snare's snappy knob. Each hit gets fresh noise.
- Pitch envelopes use time constants (909 kick, SDS-V bends restored); the 909
  snare body falls instead of rising.
- Level trims regenerated for all 143 sounds with the v9.36 policy.
- CPU: median per-voice cost 31k → 19k instructions per block; worst onset block
  215k → 125k. Emulator checks pass; hardware test pending.

## 0.6.1-alpha, build ED5E (2026-10-04)

**New**

- **Pattern Follow can be toggled with SHIFT + HOLD**  
  The pattern will stay on the currently selected measure or follow the playback head.
- **Solo is now mapped to SHIFT + ROLL**    
  The **ROLL** button blinks when solo is active.
- **The metronome can be activated with SHIFT + PAD 9**  
  Press once to toggle default metronome behavior (active during playback), press twice to toggle recmode (only active during recording)
- **EXT SOURCE can be toggled with EXT SOURCE** 
- **Time signatures visible in pattern menu**  
  Currently only show the time signature, the ability to change it will be added at a later stage.

**Fixed**
- **Playback of a new pattern with empty tracks is now supported**  
  This allows you to rehearse and record with a running metronome. Previously, an empty pattern was not playable, and adding empty tracks to the pattern would get them removed. This issue made it impossible to record patterns without creating a track with at least one note in it first.
- **REC button flickering fixed**
- **Various smaller bugs involving edge cases**

**Improvements**
- **REC button dimmed when not recording**.  
  The REC button was brighter than on the stock firmware, which could lead users to mistakenly assume REC mode was enabled.

**Miscellaneous**
- **The pattern mode now supports various time signatures internally**  
  For future stock compatibility reasons.
